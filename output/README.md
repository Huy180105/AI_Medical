# MedFusion-CXR Multi-Agent Consultation Reports

This folder stores the finalized multimodal consultation reports generated by the Master Orchestrator and Specialist Agents for incoming patients.
Each report contains:
- Primary Diagnosis & Confidence
- Differential Diagnoses
- Cross-modal Evidence Chains (CXR + Vitals + Symptoms)
- Clinical Acuity & Actionable Next Workup Recommendations
